Requisiti raccolti finora (24 novembre 2026):

- Funzioni di una lista attività completa: liste, scadenze, ripetizioni, sotto-attività, stella, riordino.
- Note organizzate come un raccoglitore: gruppi di sezioni › sezioni › pagine.
- Testo salvato in Markdown, scritto con un editor visuale.
- Tutti i dati cifrati nel database; ogni utente WordPress abilitato dall'admin ha dati separati e la propria password di cifratura, con codice di recupero e link via email facoltativo.
- PWA installabile su telefono e PC, con layout a colonne su schermo grande.
- Email inoltrata a una casella dedicata → nota (solo oggetto e corpo).
- Disegno a mano libera nelle note.
